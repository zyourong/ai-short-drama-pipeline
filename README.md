# AI Short Drama Asset Pipeline

> 剧本一键输入 → 人物 / 场景 / 道具资产自动生成

![总览效果](examples/overview.png)

## ✨ 核心特性

- 🎬 **全链路自动化**：剧本一键输入，自动完成人物 / 场景 / 道具三类资产的解析与生成，无需人工干预
- 👤 **多视角一致性**：基于 Qwen-Image-Edit-2511 的指令驱动能力，生成同角色正面 / 侧面 / 背面多视角统一形象
- 🎨 **双风格切换**：支持亚洲 / 欧美两套美术风格一键切换，适配都市、古风、悬疑等不同题材剧本
- ⚡ **批量并发调度**：5 路异步并发 + 2 小时超时保护，单集剧本资产生成效率提升约 70%
- 📦 **标准化交付**：自动按命名集分类归档，资产与剧本实体一一对应（如 `叶凡的玉佩.jpg`），可直接对接后期剪辑管线

## 📸 效果示例

### 人物多视角一致性生成
基于 Qwen-Image-Edit-2511，输入同一角色参考图，自动生成正面、侧面、背面三视图，保持身份特征与画风统一。

![场景示例](examples/scene_demo.png)

### 道具生成

## 📊 业务效果

- **生产效率提升约 70%**：单集标准剧本（约 15 个场景）可自动生成 300+ 张资产素材
- **人工操作减少 80%**：替代原有人工分镜提取 → 逐张生图 → 手动下载 → 逐一重命名的多步流程
- **资产完整率 90%**：所有资产与剧本中的实体（人物 / 场景 / 道具）严格一一对应，基本零遗漏

## 🧱 技术架构

- **LLM 层**：DeepSeek API 解析剧本，结构化提取人物 / 道具 / 场景，自动生成标准化提示词
- **调度层**：Python 异步任务调度（V2 API 轮询 + 5 路并发控制 + 2 小时超时保护）
- **生成层**：
  - **人物 / 场景**：Qwen-Image-Edit-2511 多视角一致性生成
  - **道具**：Z-Image 垂直领域微调生成
- **工程层**：ZIP 流式下载 → 多批次合并 → 按命名集重命名，资产规范化交付
