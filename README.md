# AI Short Drama Asset Pipeline

## 项目背景
解决 AI 短剧生产中的“剧本 → 资产”全自动化问题。输入完整剧本，自动生成角色、道具、场景的标准化图像资产，替代人工逐张生图与手动整理。

## 技术架构

- **LLM 层**：DeepSeek API 解析剧本，结构化提取人物/道具/场景，自动生成标准化提示词。
- **调度层**：Python 异步任务调度（V2 API 轮询 + 5 路并发控制 + 2 小时超时保护），支持批量剧本并行处理。
- **生成层**：
  - 基于 **Qwen-Image-Edit-2511** 实现多视角一致性生成（通过指令控制正面/侧面/背面视图，保持角色身份与画风统一）
  - 基于 **Z-Image** 实现道具垂直领域微调生成（纯白底商品图）
- **工程层**：ZIP 流式下载 → 多批次合并 → 按命名集重命名，资产与剧本实体一一对应。

## 运行效果

- 单次全流程自动化生成 **300+** 张高质量资产图
- 支持欧美/亚洲双风格切换
- 资产命名规范、分类清晰（例如 `叶凡的玉佩.jpg` 对应剧本中的道具）

## 快速开始

```bash
python pipe.py
# 按提示输入 API 密钥、剧本内容、输出目录即可
```

## 目录结构

```
├── pipe.py                  # 核心调度脚本
└── workflows/               # ComfyUI 工作流定义
    ├── prompt_workflow.json # 提示词生成工作流
    ├── char_workflow.json   # 人物多视图生成工作流
    ├── prop_workflow.json   # 道具生成工作流
    └── scene_workflow.json  # 场景四视图生成工作流
```
